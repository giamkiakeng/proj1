\section{Reproducibility}\label{app:repro}

The directory \texttt{fssp5/} of the accompanying repository contains all
programs, the rule tables and the logs. The main components are:
\begin{description}[style=nextline,leftmargin=1.5em,font=\normalfont]
\item[\texttt{src/fsspcheck.c}] independent brute-force simulator: reads a
  rule table and checks minimal-time synchronization for a range of lengths
  (full simulation of every line, no use of the agreement lemma);
\item[\texttt{src/gencnf.py}] CNF generator for $\mathrm{MT}_k(\mathcal N;M,N')$
  with the options of \cref{sec:encoding} (return chains, pumping, links,
  symmetry breaking) and the restricted classes used in the experiments;
\item[\texttt{src/pumping.py}] computation of the cones of
  \cref{lem:cone} by breadth-first search and direct verification of
  $\mathrm{PUMP}(n,n')$ on a given rule;
\item[\texttt{src/fsspdfs.c}] exhaustive depth-first enumeration of partial
  rules (\cref{tab:four});
\item[\texttt{src/mazoyer\_from\_coq.py}] extraction of Mazoyer's rule from
  the file \texttt{autom.v} of Duprat's Coq development \cite{Duprat97};
\item[\texttt{src/validate\_mazoyer.py}] soundness test of the encoding;
\item[\texttt{src/check\_halfline.py}] direct check that a half-line
  diagram has no firing cell below a given anti-diagonal;
\item[\texttt{src/fixgerm.py}, \texttt{src/knuth.py},
  \texttt{src/benders.py}] the experiments of \cref{sec:five};
\item[\texttt{src/germdfs.c}] enumeration of the half-line germs of
  bounded complexity (\cref{prop:germs});
\item[\texttt{src/germinc.py}, \texttt{src/germcert.py}] completion tests
  of germs (CaDiCaL under assumptions) and a single LRAT certificate for a
  list of refuted germs;
\item[\texttt{src/germext.c}, \texttt{src/germext2.c}] extension of the
  half-line determined by a germ, and the checks of \cref{lem:left} and
  \cref{lem:pumping} on it (\texttt{germext2.c}: streaming version of the
  check of \cref{lem:left} for a single long line);
\item[\texttt{src/germcompare.py}] the neighbourhoods used by the half-line
  of a rule below a given anti-diagonal (\cref{thm:frontier}(c)).
\end{description}
The directory \texttt{results/germs} contains the germ lists, the logs of
the classification and, in \texttt{CERTIFICATES.txt}, the digests of the
certificates.

\paragraph{Checking \cref{thm:frontier}}
{\footnotesize
\begin{verbatim}
R=results/uniformA_2-12.txt
fsspcheck $R 2 12              # OK for all 2 <= n <= 12
fsspcheck $R 13 13             # FAIL: a cell fires at time 23
python3 pumping.py $R 40       # 0 violations
python3 check_halfline.py $R 78  # no firing cell, t+i <= 78
S=results/delta13.txt
fsspcheck $S 2 13              # OK for all 2 <= n <= 13
fsspcheck $S 14 14             # FAIL: a cell fires at time 21
python3 pumping.py $S 40       # 0 violations
python3 check_halfline.py $S 78  # no firing cell, t+i <= 78
python3 germcompare.py $R $S 78  # identical, 22 besides (L,L,L)
\end{verbatim}}
The uniform configurations before firing in (a) and (b) are visible with
the option \texttt{-v} of the checker, which prints the diagrams.

\paragraph{Checking \cref{cor:germ12,prop:chaotic,prop:germs}}
{\footnotesize
\begin{verbatim}
gcc -O2 -o germext germext.c && gcc -O2 -o germdfs germdfs.c
# Corollary 6.2: germ of delta12/delta13 (22 neighbourhoods)
./germext 5 1300 3 6 < ../results/germs/germ_delta12.txt
                    # CLOSED; REFUTED n=518 s=2 L=1 Y=259
# Proposition 6.3
./fsspcheck ../results/delta14.txt 2 14           # OK
./fsspcheck ../results/delta14.txt 15 15          # FAIL: fires at time 22
./germext 5 10000 3 24 800 < ../results/germs/germ_delta14.txt
                    # CLOSED, no refutation
# Proposition 6.4 (complexity <= 14)
./germdfs 5 78 14 40 > germs_K14.txt              # 244 germs
python3 germinc.py germs_K14.txt 10 78            # 230 UNSAT, 14 SAT
python3 germcert.py ../results/germs/K14_refuted10.txt 10 k14_n10
                                                  # UNSAT, VERIFIED
./germext 5 3300 3 12 < germs_K14_surv10.txt      # 14 x REFUTED (s=1)
\end{verbatim}}
The files \texttt{results/germs/germ\_delta12.txt} and
\texttt{germ\_delta14.txt} contain the two germs in the one-line format of
\texttt{germdfs.c}, as printed by \texttt{germcompare.py --germline}; the
complete pipeline for complexity at most $16$ is \texttt{germpipe.sh}.

\paragraph{Validation against Mazoyer's solution}
{\footnotesize
\begin{verbatim}
python3 mazoyer_from_coq.py autom.v > mazoyer6.txt
fsspcheck mazoyer6.txt 3 3000   # OK for all 3 <= n <= 3000
python3 validate_mazoyer.py 14  # SAT under exactly one renaming
\end{verbatim}}
