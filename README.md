# Minimal-time firing squads: two necessary conditions

This repository accompanies the note *Two necessary conditions on minimal-time solutions of the firing squad problem* by Kia Keng Giam, Beichen Sun and Yaoqi Zhao.

- The note: `fssp5/note/note.pdf` (source in `fssp5/note/`).
- The programs, rule tables, logs and certificate digests behind its computer-assisted statements are in `fssp5/`.
- `fssp5/README.md` gives the command that checks each statement.
