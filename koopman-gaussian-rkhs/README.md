# Koopman invariance of Gaussian RKHSs for linear SDEs

This manuscript resolves the open problem of Philipp, Schaller, Worthmann, Peitz and Nüske
(arXiv:2405.14429, PAMM 25(1), 2025). They proved that the Lyapunov-type condition
½(AC² + C²Aᵀ) ≤ BBᵀ is sufficient for the Gaussian RKHS H_C to be invariant under the Koopman
semigroup of dX = AX dt + B dW. The manuscript shows that the condition is not necessary. The exact
condition is ½(AC² + C²Aᵀ) ≤ 2BBᵀ.
